# Plan: Fashion Aura B2B Catalogue Website

## Goal
Boss want B2B catalogue website for client **Fashion Aura**.
Import export business. Show product, get quote. No pay cart.

## Categories & Items
- **Sports Wear**: Soccer, Basketball, Rugby, Sublimation
- **Fashion**: Hoodies, Sweatshirts, Leather

## Tech Stack
Boss choose: **React + Vite + Standard CSS** (Clean, fast, custom modular CSS, no Tailwind, no Angular overhead).

## Proposed Architecture
- **Home**: Hero banner, export strength highlight, category cards, featured items, inquiry form
- **Catalogue Page**: Filter by Category (Sports / Fashion) and Sub-category (Soccer, Rugby, Hoodies, Leather, etc.)
- **Product Detail / Modal**: High-res gallery, fabric specs, MOQ (Minimum Order Quantity), custom branding options, "Request Quote" button
- **Inquiry / RFQ System**: WhatsApp direct chat + Email quote form (collect quantity, customization details)
- **About / Export Info**: Worldwide shipping details, manufacturing capabilities, certifications
- **Contact Page**: Location, direct contact, export inquiry form

## Verification Plan
### Manual Verification
- Check all catalogue items filter fast.
- Check "Request Quote" button open WhatsApp or email form with product name filled.
- Check mobile responsive design.
